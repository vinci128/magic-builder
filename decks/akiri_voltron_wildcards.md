# Akiri voltron — wildcard upgrades

`akiri_voltron_brawl.decklist.txt` is the deck as owned; `akiri_voltron_brawl_upgraded.decklist.txt`
is the same deck with the 36 crafts below swapped in. Every card was checked against Scryfall as
available on Arena, Brawl-legal and inside R/W identity (Sept 2026). Craft in tier order — each
tier stands on its own, so stop wherever the wildcards run out.

Wildcards: 8 mythic, 16 rare, 12 uncommon.
