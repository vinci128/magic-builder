Build a deck from the cards you actually own.

Most deck builders start from every card ever printed and leave you to work out what you can afford. This one starts from your binder — it reads your collection, scores what is already in it, and builds the best deck those cards can make.

Nothing to install. Drop in a ManaBox or MTG Arena export and it builds the deck in your browser:

Open the web app →

Or keep it on your machine. There is a small example collection bundled, so you can see the output before exporting anything of your own:

uvx magic-builder --demo

What it does

Starts from your collection

Reads a ManaBox CSV, an MTG Arena deck export, or an Arena collection CSV — auto-detected. What it builds, you can actually sleeve up today.

Five formats

Commander and Brawl (100-card singleton), Standard, Pauper and Modern (60 cards, 4-of, with a 15-card sideboard filled from your leftovers).

Names the deck

The way players do — colour identity plus the theme the scoring actually followed: Rakdos Midrange, Orzhov Lifegain, Golgari Elves. Falls back to a shape word when no theme has enough cards behind it.

The bracket, with evidence

Every Commander and Brawl deck is placed on brackets 1–5, and it shows its work: Game Changers, land denial, extra turns, tutors, two-card combos, how fast the deck actually is.

How close are you to the meta?

--meta modern ranks the current MTGGoldfish archetypes by how much of each list you already own, what is missing, and what the missing cards cost — in paper dollars and Arena wildcards.

Prices everywhere

Every card, deck and recommendation is priced from Scryfall at the cheapest printing. The acquisition list tells you what the deck would cost to finish.

Also in the box

  • A web interface — the hosted one needs no install at all, or run magic-builder-web locally. Either way: upload a collection, see the deck with its curve, pip demand, sideboard, recommendations and card art.
  • An MCP server — magic-builder-mcp exposes the core as tools, so an assistant can build and iterate on decks conversationally.
  • The precons you own — recognises preconstructed decks in your collection and says what to swap into each, from cards you already have.
  • EDHREC recommendations — what other players run with your commander, split into cards you own and cards you would need, each labelled Staple / Flex / Tech and priced.

Install

pip install magic-builder

Also uv tool install magic-builder or pipx install magic-builder. Python 3.12+. On PyPI as magic-builder, and the source is on GitHub.

The hosted web app is on a free tier. It sleeps when nobody uses it, so the first request after a quiet spell takes half a minute to wake — a spinner, not a crash. Nothing is stored on that server beyond the 20 most recent uploads, held in memory and gone when it restarts; run it locally if you would rather it never left your machine.

What it needs, plainly. A collection export to be useful — ManaBox and MTG Arena both produce one, and the format is detected automatically. The first run downloads Scryfall's card database (~80 MB, cached in your user cache for a week); after that everything is local except the optional EDHREC and metagame lookups. The bundled example is a synthetic 29-card list, not anybody's collection.

No account, no sign-up, no telemetry. It runs on your machine and your collection never leaves it.
